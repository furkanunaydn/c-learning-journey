## 🧠 My Learning Process

For each exercise, I generally follow these steps:

1. Try to understand and solve the problem myself.
2. Write and test my own solution.
3. Compare my solution with the instructor's approach.
4. Identify mistakes and improve my code.
5. Commit the completed work to GitHub.

This means the code here is my own — I use the exercises as specifications, write my own implementations, and learn from the differences.
